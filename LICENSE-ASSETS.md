3D props (`public/props3d/*.glb`) are data for the glTF loader of Three.js: geometry, plain materials, animation. `inspectGlb` in `scripts/import-art.mjs` refuses a model that names a file outside itself, uses an extension, or holds a texture or a skin, and a test runs it over every model that ships. All other files are served unchanged from the app origin and are loaded only as images: through `<img>`, canvas `drawImage`, or an `Image` object that becomes a WebGL texture (image mode: no script runs, no subresource loads). As a supply-chain guard, `unsafeSvg` in `scripts/fetch-fluent.mjs` refuses SVG text with script, event handlers, style, entities, processing instructions, `use`, `image`, `foreignObject`, links, animation or any non-fragment `href`, `src` or `url()`; the test `sticker svgs are art, not code` runs the same check over every shipped file.

Excluded on purpose: OpenMoji (CC BY-SA), JoyPixels (personal use), unscoped `soundtouchjs` (LGPL). Allowed licenses for this project: MIT, Apache-2.0, BSD, MPL-2.0, Unlicense, CC0, CC-BY.
